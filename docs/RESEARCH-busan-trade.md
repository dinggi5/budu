## 5. 읽은 것 — 기획에 주는 시사점

1. **«스테이블코인을 보내는 것» 은 이미 쉽다. 병목은 «증빙» 과 «제도» 다.** 청구스(청구서↔입금 매칭)·트레이드왈츠(선적 서류→결제)
   모두 **돈과 무역 서류를 잇는 쪽**에 가치를 둔다. 송금 자체로 승부하면 갤럭시아·은행 컨소시엄과 붙는다.
2. **한국 무역 중소기업이 해외 대금을 USDC 로 주고받는 건 지금 합법 경로가 좁다.** 피치에서 «지금 쓴다» 가 아니라
   «제도가 열리는 날(12-03 외환법 시행 → 후속 입법)에 맞춘 도구» 로 말해야 한다. 데모는 데브넷.
3. **AI 에이전트가 들어갈 자리는 무역 «백오피스»** — 운임 견적, HS 코드, 선적·반출입 확인, 서류 대조. 이건 지금도 합법적인
   소액 데이터 구매(x402)이고, 우리 지갑의 승인·한도·내역이 그대로 맞는다.
4. **부산 고유 자산 = 항만 데이터.** 체인포털·포트아이는 외부 API 가 안 보이지만, 해수부 반출입 공공 API 는 있다.
   «부산항 데이터를 에이전트가 건당 사서 쓰게 하는 x402 게이트웨이» 는 오픈소스·조합 가능성 칸에도 맞는다.
5. 부산 클러스터는 **올해가 마지막 해**, 청구스 같은 지역 플레이어가 수출대금 정산을 먼저 잡고 있다. 경쟁이 아니라
   «우리는 AI 에이전트 쪽 승인·증빙 레이어» 로 자리를 나누는 게 낫다.
